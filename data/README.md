# Datos para desarrollo y comprobación

- [wide-world-importers/](wide-world-importers/README.md): dataset ficticio de
  Microsoft seleccionado para el MVP, originales y exportaciones CSV/Excel.
- [reference-cases/](reference-cases/README.md): casos pequeños derivados de WWI,
  con entradas, variantes y respuestas de evaluación separadas.
- [exploratory/](exploratory/README.md): otros datasets públicos que se investigaron
  antes de seleccionar WWI.

Los originales importados por la aplicación, tablas preparadas y resultados de
ejecución se guardan de forma privada en `.local/storage/`; los metadatos residen
en PostgreSQL local. Esta carpeta reúne los datos de muestra del proyecto.
